hookjudge

只判断：一条事件，一个裁决，一笔账 帮助 加载中…

这是什么

hookjudge 是管道背后的判官：收一条标准化事件，给一个裁决（重要性、分类、一句话摘要）， 回传给管道，同时记一笔账。它不渲染卡片、不管渠道 — 那些是管道的活；也不做深度排查 — 那是调查员的活。判官只回答「这条告警值不值得打扰人」。

四条路由 = 成本策略（顺序就是策略本身）

路由什么时候走花钱吗
recovery恢复事件继承其告警当初的裁决 — 目的是与所属告警口径一致，而不只是省一次调用免费
reuse窗口内（默认 1h）同一状况的复述，沿用上一次 AI 裁决 — 告警风暴是同一件事的重复陈述免费
ai真正没见过的新状况，问模型付费
rule模型没配/超时/答非所问时的关键词兜底；degraded_reason 会写明为何降级，绝不冒充分析。对已知级别保守沿用免费

省钱的关键不是把模型调便宜，而是让大多数事件根本走不到 ai。

读这块板子

四张卡：24h 裁决量 / 付费比例（ai 占比）/ 24h 花费 / 回传失败（>0 说明管道收不到裁决 — 配了 HOOKJUDGE_ALARM_URL 会绕开管道直发自告警）。裁决行的徽章就是路由，旁边是延迟与单笔费用。

API 与地址

家族容器网络内 http://hookjudge:8200；宿主机回环映射 http://127.0.0.1:8200。

端点用途
POST /events管道投来的标准化事件（可选时间戳 HMAC 签名）。答 202 立即返回 — 裁决走回传门送回，不占着连接
GET /status本页数据源（X-Read-Token）
GET /healthz · GET /metrics存活 / Prometheus 文本

关键旋钮

env含义
HOOKJUDGE_AI_BASE_URL / _API_KEY / _MODELOpenAI 兼容端点。留空 = 每条都走 rule 兜底（能用但钝，且 reuse 永远不会发生）
HOOKJUDGE_REUSE_WINDOW_SECONDS复述窗口（默认 3600）
HOOKJUDGE_RETURN_URL / _RETURN_SECRET唯一的出口 — 管道的 judge-notify 门；退避重试，耗尽进死信并自告警
HOOKJUDGE_RETENTION_DAYS · HOOKJUDGE_ALARM_URL账本保留（默认 30 天）/ 死信自告警直达地址
